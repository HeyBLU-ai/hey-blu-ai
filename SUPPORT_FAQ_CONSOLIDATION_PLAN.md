# Support & FAQ Consolidation Plan

## Problem
- `/support` page created for Apple App Store requirements (approved, not released)
- `/faq` page created with better UX and overlapping content
- Duplicate information causing user confusion
- Need to comply with Apple App Store requirements

## Apple App Store Requirements
✅ Must have a working support URL (`/support`)
✅ Must clearly identify the app (HeyBLU)
✅ Must provide contact method (email)
✅ Must be live and accessible

## Solution: Hybrid Approach

### 1. `/support` Page (Apple App Store Compliance)
**Purpose:** Minimal compliance page that redirects users to FAQ
**Content:**
- App identification (HeyBLU logo and name)
- Contact email (support@heyblu.ai)
- Prominent link/redirect to `/faq`
- Bug reporting form (keep for App Store compliance)
- Simple, clean design

### 2. `/faq` Page (Primary User-Facing Help)
**Purpose:** Main help page with all user resources
**Content:**
- Pre-game checklist (keep)
- FAQ questions (keep)
- Add bug reporting form (from support page)
- Add TestFlight info (link or section)
- Add "Contact Support" section
- Better visual design (keep)

### 3. Navigation Updates
- Remove "Support" from main nav (keep FAQ)
- Keep "Support" link in footer (points to `/support` for App Store)
- FAQ becomes primary help destination

## Implementation Steps

1. ✅ Create minimal `/support` page with:
   - App identification
   - Contact info
   - Redirect/prominent link to FAQ
   - Bug reporting form

2. ✅ Enhance `/faq` page with:
   - Bug reporting form
   - TestFlight link
   - Contact support section

3. ✅ Update navigation:
   - Remove Support from main nav
   - Keep Support in footer
   - FAQ remains primary

4. ✅ Test Apple App Store compliance:
   - `/support` URL works
   - App clearly identified
   - Contact method visible
   - Links to comprehensive help

## Benefits
- ✅ Meets Apple App Store requirements
- ✅ Eliminates duplicate content
- ✅ Better user experience (one primary help page)
- ✅ Cleaner navigation
- ✅ Maintains bug reporting functionality
