Get Your League's Rules Live

Submit one division at a time. We typically turn around pilot access within a few business days after we receive a clean Word document.

The org-wide rulebook (Little League, MLB, etc.) — not your local division exceptions in the link below.

Preferred format: Word (.docx)

  • Share a viewable link to your file (Google Drive, Dropbox, OneDrive, or league website).
  • Keep it under 4.5 MB and rules only — remove snack schedules, board emails, and other admin filler.
  • Bold each rule header on its own line so our engine can parse sections correctly.

Use a share link that anyone with the link can view. One division per submission — submit again for each additional division.

PDF only? Read this first

We can work from PDFs, but they take longer to process and may incur a paid conversion fee because of higher extraction costs. The fastest (and currently free) path is a clean .docx export from Word.

In Word: File → Save As → Word Document (.docx). If you only have PDF, still submit the link above and note it in the optional comments — we'll follow up with timing and any fees.
